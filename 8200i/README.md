# Plustek OpticFilm 8200i — capture methodology

This directory contains USB captures of a Plustek OpticFilm 8200i using the vendor
Windows driver / SilverFast 9, following the same capture methodology as the
[8200i-se](../8200i-se/) dataset in this repo. See [SESSIONS.md](SESSIONS.md) for the
session index.

## Device

| Field | Value |
|-------|-------|
| Model | Plustek OpticFilm 8200i |
| USB | `07b3:130d` |
| ASIC | Genesys GL845 |
| Capture application | SilverFast 9 / vendor Windows driver |
| Host OS | Windows 11 25H2 |
| Film | 35 mm negative |
| Capture method | Wireshark + USBPcap |
